# GUIAug Frontend

Vue-based interface for recording and replaying seed GUI test scripts and invoking the backend’s Input-Aware and Intent-Aware Augmentation workflows.

The current paper-aligned execution path controls an Android device through the ADB backend. The frontend retains the existing labels `INPUT-DATA` and `PATH`; these correspond to the paper terms **Input-Aware Augmentation** and **Intent-Aware Augmentation**, respectively.
